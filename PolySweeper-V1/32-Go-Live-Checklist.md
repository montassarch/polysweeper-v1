# Ready for real money checklist

Back to [[V1-Home]] · Tasks: [[24-Task-List]] · Results: [[26-First-Shadow-Results]]

The "go" decision for the first **$20** (target date 1 November 2026) must be a fact, not a feeling. Every box must be ticked
**for the one rule we will trade** (not for all rules together). The numbers are a first proposal;
the owner can change them, but only before looking at the results, never to make a rule pass.

## 1. Proven in shadow mode

- [ ] **200+ settled pretend trades** on that rule (at ~0.99 one loss costs ~100 wins, so fewer
  trades cannot show a loss rate below 1%).
- [ ] **0 losses** on that rule. One loss = back to the drawing board for that rule.
- [ ] At least **14 days** of running, covering both weekdays and weekends.
- [ ] Every trade bought **after the result was certain** (never "price only" during play).

## 2. Realistic profit

- [ ] **Fill rate measured**: second-look check (are the shares still there ~2 s later?) and
  public-trades check (did someone else take them first?) on every pretend buy.
- [ ] Profit **still positive** after removing the trades we would probably have missed and
  after fees.
- [ ] Enough trades a day to matter: at least **5 a day** on average.

## 3. System safe to hold money

- [ ] Bot ran **7 days** in a row with no crash and no data gap over 1 hour.
- [ ] **Automatic go-back** works: a bad update returns to the last working version (tested once on purpose).
- [ ] **Phone alerts** work: no new data for 4 hours, errors piling up, any pretend loss (each tested once).
- [ ] **Emergency stop** works from the phone (tested once).

## 4. Money rules written down

- [ ] Start with **$20** on **1 November 2026** (owner decision 2026-10-05; was $50); max **5 shares** per trade, max **3 open trades** (5 shares at ~0.99 is ~$5 each).
- [ ] **Stop for the day** after any loss; stop everything after 2 losses in a week, review first.
- [ ] Deposit and withdrawal cost checked (a fixed $3 fee would be 15% of $20).
- [ ] Wallet keys kept only on the owner's PC; real orders only after the owner says **"go"**.
